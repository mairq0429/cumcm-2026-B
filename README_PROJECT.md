# B题数学建模项目管理说明

本项目中的现有 `B_code` 代码包含已通过官方模拟器验证的实现。未经明确评审，不移动、不删除、不覆盖、不重构已有代码。

## 目录作用

- `00_official/`：官方题目、附件与模拟器文档的归档位置。
- `01_team/`：团队状态、模型与代码规格、交接、问题、决策和文献跟踪。
- `B_code/`：现有代码及新增的冻结、开发、测试和工具目录。
- `03_results/`：练习、压力测试、消融、敏感性、正式运行和绘图数据。
- `04_paper/`：论文材料、图、表、参考资料和草稿。
- `05_submission/`：提交源码、日志、结果和运行说明。
- `06_backup/`：按时间生成的项目备份。

## 三个人职责

| 角色 | 主要职责 | 当前负责人 |
| --- | --- | --- |
| 成员一 | 模型推导、假设与参数来源核验、维护 `MODEL_SPEC` | 待填写 |
| 成员二 | 代码实现、测试与模拟器验证、维护 `CODE_SPEC` | 待填写 |
| 成员三 | 结果汇总、图表与论文整合、提交材料检查 | 待填写 |

所有成员共同维护 `TEAM_STATUS`、`ISSUES`、`DECISIONS`、`CHANGELOG` 和 `HANDOFF_LOG`。

## 工作流

`MODEL_SPEC` → `CODE_SPEC` → 程序实现 → 模拟器验证 → `RESULTS_MASTER` → 论文

1. 先在 `MODEL_SPEC` 明确模型版本、输入输出、假设、参数来源和验证方法。
2. 在 `CODE_SPEC` 绑定模型版本、源文件、函数、测试文件和算法版本。
3. 在开发目录实现或调整程序，不改动已冻结且通过验证的版本。
4. 使用官方模拟器验证，并保存真实日志。
5. 将真实运行信息登记到 `RESULTS_MASTER.xlsx`，不得编造实验数据。
6. 论文只引用已经核验的模型、代码、实验结果与真实文献。
